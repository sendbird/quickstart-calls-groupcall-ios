## Introduction

This repository contains iOS sample apps that show how to build group voice and video calls in rooms with [Sendbird Calls SDK for iOS](https://github.com/sendbird/sendbird-calls-ios).

| Folder | Description |
|---|---|
| [`groupcall-uikit/`](groupcall-uikit) | Sample app built with UIKit and storyboards. Requires iOS 15.0 or later. |

Each folder is an independent Xcode project. Open the project in the folder you want to try and follow the README in that folder.

### More about Sendbird Calls for iOS

Find out more about Sendbird Calls for iOS on [Calls for iOS doc](https://sendbird.com/docs/calls/v1/ios/getting-started/about-calls-sdk). If you need any help in resolving any issues or have questions, visit [our community](https://community.sendbird.com).
